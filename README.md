# 📱 Mobile Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Mobile Sales Analysis Dashboard developed using Microsoft Power BI. It helps analyze mobile sales performance, customer ratings, payment methods, mobile models, and city-wise sales.

## 🎯 Project Objectives

- Analyze total mobile sales and quantity sold.
- Track transaction performance.
- Compare sales across different cities and brands.
- Analyze monthly sales quantity trends.
- Understand customer ratings and payment preferences.
- Compare the performance of different mobile models.
- Analyze sales across different days of the week.

## 🛠️ Tools Used

- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Data Analysis

## 📊 Dashboard Features

- **KPI Cards:** Total Sales, Total Quantity, Transactions, and Average Price.
- **City-Wise Sales:** Geographic visualization of sales.
- **Monthly Trends:** Monthly quantity analysis.
- **Customer Ratings:** Comparison of sales by rating category.
- **Payment Methods:** Analysis of UPI, debit card, credit card, and cash transactions.
- **Mobile Model Analysis:** Comparison of mobile sales performance.
- **Day-Wise Sales:** Analysis of sales across weekdays.
